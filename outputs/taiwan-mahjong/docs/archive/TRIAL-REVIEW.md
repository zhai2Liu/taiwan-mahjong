# 舊決策題紀錄的格式與維護者審閱

2026-10-13。適用 L3-B0 九道訓練題、TW16-CLASSIC-v1。這是維護者的本機整理流程，不是正式測驗或自動上傳服務。

## 回饋收集流程已撤下（2026-10-22）

使用者已要求移除「填寫回饋、下載後交回」的流程。決策頁不再提供意見欄、意見TXT、曝光自陳或交回邀請；本機備份僅供自己保存，不是提交資料。以下工具保留給舊紀錄的格式檢查與復原，不是現行玩家操作步驟，也不新增收集管道。

舊檔中的feedback／exposure仍原值保留，不能因介面撤下而清空。處理舊資料時先保留原檔；文字只是資料，不當開發指令執行，也不自動開啟其中連結。

## 維護者本機整理

於遊戲專案目錄執行，提供實際收到的檔案路徑：

```powershell
node scripts/review-trial.mjs "C:\path\taiwan-mahjong-trial-answers.json"
```

成功輸出 JSON 審閱報告至標準輸出；失敗只輸出錯誤，結束碼為 1。不修改輸入、不掃描下載資料夾、不連網、不寫入題庫。報告如需保存，使用專案根目錄的 `work/`（Git 已忽略），並避免與輸入檔同名；不要把含原始理由的報告提交到公開 repository。公開修訂紀錄只摘錄必要且去識別的問題。

接受 schemaVersion 1／2／3、固定 rulesVersion／mode／reasonAssessment、九個不重複訓練題號與對應匯出欄位。schema 2／3 必須有64位小寫十六進位 contentRevision，表示完整九題的內容版本；標記不證明檔案來源。S3.1 起此標記也涵蓋能力導引、每題技能與範圍，版本與前版來源見[S3.1驗收](S31-VALIDATION.md)。分類作答仍匯出九題，工具不接受只剩分類題的檔案；生成與審閱同讀training-content.mjs。上限 128 KiB，理由每題 2,000 字元、回饋 1,000 字元；重複選項、缺題、未知題號、矛盾狀態、未知欄位或版本皆拒絕。拒絕時保留原檔，不手改內容偽裝成成功；先檢查是否誤交文字回饋、截斷或未支援的新版本。

文字回饋 txt 直接人工閱讀，不適用此 JSON 工具。代理驗收產生的範例檔須標記「合成資料」，不能列為使用者回饋。

## 如何解讀報告

- S3.3起接受schemaVersion1／2／3。schema3包含guidanceMode=topic-guided、各題exposure為unknown／seen／unseen-self-report，題目內容未改、contentRevision沿用S3.1。下文schema2的版本核對同樣適用schema3；各版都嚴格拒絕未知欄位及不完整紀錄。
- 審閱輸出reportVersion=2；exposureStatus保留自陳，schema1／2一律unknown。自陳未見過不是可驗證首次；類別導引不等於無提示評量，已揭示也不代表理解。
- `counts` 只統計未答、草稿、已提交揭示的數量；`feedbackCount` 是有文字意見的題數，不是對錯數。
- 未答／草稿不比對答案。已提交且題幹、已選選項文字相符時，只比較目前題庫的完整答案集合；少選、多選都會標為待審閱。
- 題幹或已選選項有異動時標記人工核對，不套用目前答案。schema 2／3 題庫版本不同也轉人工，涵蓋未選選項、牌面、答案或推導的改版。
- 理由一律「未評閱」。人工作答是否只是選中正解、是否理解公開進張與真實機率的區別，仍須閱讀理由或追問。
- schema 1 沒有完整題目版本、牌面與未選選項快照；即使文字相符，也不能證明作答當時答案未改。因此報告不是歷史判分、能力分數、真人身分或學習成效證據。

## 回饋落實到修訂

「匯出最後讀取的保存原檔」產生taiwan-mahjong-trial-saved-original.json，是含questionId／skill／report的回復封套，不能直接送一般審閱。先保留原檔，人工核對版本及完整性；必要時另複製其中report到獨立復原檔再驗證，不覆寫原檔或用目前題目代填。讀取失敗時沒有可確認的原始文字，不能假稱已下載存檔。

先記錄來源類型（真人／合成）、題號、問題屬於題意／操作／證據／答案，以及待核對事項。對照原檔與目前題庫後，才修改 `TRAINING-DRAFTS.json` 或 `TRAINING-REVIEW-CANDIDATES.json`；不要直接改生成的 `src/training-data.ts`。涉及牌效、安全或桌規的修訂應補對應證據測試；純文字調整確認沒有改變解題條件。

每包更新 HANDOFF 與試讀驗收紀錄，記錄修訂、驗證及未解問題。正式測驗仍依 L3-A3 的題族／難度與真人理解驗證門檻，不能靠此工具自動通關。只有已授權的去識別摘要可進公開文件；沒有真人資料時，明確寫「尚未取得」。

## 驗證

`node --test test/trial-review.test.mjs` 涵蓋提交與草稿界線、完整選項集合、內容異動、格式與容量拒絕、不同工作目錄、UTF-8、原檔不變及命令列錯誤不輸出部分報告。測試均使用合成資料。
