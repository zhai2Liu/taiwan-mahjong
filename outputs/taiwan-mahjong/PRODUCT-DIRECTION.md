## 已採納定位

**從零到一百的麻將路｜台灣十六張麻將學習與決策練習。**

2026-10-18：依使用者指定「從零到一百的___」命名句型並交由代理補完，顯示名稱採「從零到一百的麻將路」，涵蓋從認牌、練習到對戰的學習過程；名稱不代表已提供一百課或經驗證的能力等級。既有網站網址、repository與本機資料鍵沿用；舊版展示與驗收保留當時名稱。

- 新手：認牌、合法摸打與回應、聽胡及基本結算，循序銜接正常對戰。
- 已會打牌的玩家：牌效、公開安全證據、吃碰代價、莊家／連莊取捨與局後檢討。
- 直接遊玩：一位真人與三位公平本地電腦，無課程解鎖限制。

新手及進階兩條學習路線共用 TW16-CLASSIC-v1。現行六步導覽與練習已可用；S2.1新增前三課入門試用版與獨立進度，發布與限定驗收見[HANDOFF](HANDOFF.md)。第4–8課及真人驗證仍待，不能稱完整八課已完成；[首頁三入口重設計](HOME-REDESIGN-20261018.md)依使用者回饋整理學習／練習／對戰及優先續玩，發布狀態仍依HANDOFF。

優先順序為規則／資料可信 → 操作可用 → 能理解與練習 → 可量測 → 實戰遷移。作品集入口與工程案例並行整理，不取代產品品質。

## 成功指標與證據界線

新手以另一牌例能否獨立完成合法操作、辨認聽胡與讀結算為目標；進階以相同能力、不同題族、無提示情境的判斷及理由改善為目標。記錄版本、提示與協助情況。

勝率、總點數、AI 一致率、閱讀進度及測試數均不能單獨證明學會。目前尚無獨立真人題意／學習成效證據；模型複核與合成資料驗收分開標示。靜態公開題庫與本機首次曝光紀錄不提供防作弊認證。

## 固定與延後範圍

| 決策 | 現行約束 |
|---|---|
| 規則 | 固定 TW16-CLASSIC-v1；不宣稱全台桌規唯一標準，不導入港麻／日麻胡牌或計分 |
| 既有對戰 | 完整行牌／計台／續局與現行公平 AI 作基線 |
| 證據 | 確定計算、條件安全、目標偏好各明示；未校準放槍率／長期收益不進正式評分 |
| 新手 | 由「維護不擴充」改為 S2 分批八課；原操作導覽繼續保留 |
| 進階 | 維持 L 線題族／難度／真人關卡，按 S3 完善；不等八課完成才處理既有問題 |
| 作品集 | S0 先做入口、架構、真實角色及案例；S5 收斂展示與版本 |
| 資料 | 靜態 Pages、本機保存；既有對戰／練習／檢討相容，新進度另定版本與清除契約 |
| 平台 | 桌面優先、窄畫面可用；指定手機／Safari 支援待實機驗收 |
| 人性化 AI | S6／L5 條件式再立案；原先「目前不實裝」指示仍有效，需另外啟動 |
| 排除 | 真人連線、帳號、後端、課金、雲端同步、多桌規、貨幣及排行榜 |

完整回放／分支與長期收益模型延後。題數與真人樣本量由能力缺口及驗證方案決定，60 題與 6–10 人不是硬性交期或充分證據。

「不讓莊家連莊」保留為局況取捨題材；流局仍續莊，普通放槍安全不等於阻莊成功。研究權重不是客觀風險機率。

## 現況與品質關卡

| 關卡 | 要求 | 現況 |
