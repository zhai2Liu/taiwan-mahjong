## 第7課：帶你打一局

目標：串起認牌、輪到誰、摸打補花、回應與結算；每次停下時，玩家知道正在等誰做什麼。不要要求先背全部台表或追求最佳打牌。

給玩家的開場文字：「這是固定牌序的教學示例。我們分段走完一局；先看輪到誰，再做一個動作。你可以查提示、再試或返回。先學會合法完成一局，不必每一步都找最佳打法。」

### 固定示範主線

你在畫面下方，下家是這局莊家。你是北門，初手`134萬、789萬、456筒、789筒、56條、南南`，共16張。起手無花，其他家手牌保持遮蔽。下列「其他家行動」是示例劇本；正常玩法不讀牆序來替AI挑牌。

| 段落 | 給玩家的任務 | 正常引擎流程與完成後回饋 |
|---|---|---|
| 開局 | 指出這局誰先打、自己是否先摸 | 從發牌及起手補花檢查開始；下家莊家17張先打九萬，莊家沒有再摸一次。「你找對莊家，先等他打牌。」 |
| 輪到你之前 | 看對家、上家依序摸打，辨認下一步等誰 | 對家摸打紅中、上家摸打發財，回應結束才輪到你。「沒有吃碰胡改變順序時，輪到下家。」 |
| 摸花 | 按摸牌，辨認冬花並補牌 | 自己摸冬，先亮花，手中仍16張；牌尾補九條到17張。「你先補好花，再選牌打出。」 |
| 打一張 | 在示範引導下打九條 | 打回16張，完成回應後繼續。第一次提示只指出這張剛補入，不說這是所有局況最佳選擇 |
| 等上家 | 確認這張牌來源 | 下家摸打白板、對家摸打北風、上家摸打二萬；進入自己的回應。「二萬由上家打出，這次可以檢查吃法。」 |
| 吃牌選擇 | 找13與34兩吃法，實際任選一種 | 13吃成123、或34吃成234都接受；其他家按過，仲裁後才把牌放桌上。只檢查合法流程，不判其中一種必然牌效最好 |
| 吃後打牌 | 13吃後打剩下的四萬；34吃後打剩下的一萬 | 不再摸一張、不立即槓。這兩個已驗分支接相同後續示例。「吃牌後你先打完，現在等下一家。」 |
| 聽與胡 | 說出聽四條／七條；輪到自己摸七條時判斷可胡 | 其他家依序摸打紅中、發財、白板，再輪到你；七條普通自摸合法，形成五組加南南眼睛 |
| 讀結算 | 指出台項、付款者及下一局莊家 | 自摸1＋冬正花1＝2台；莊家付60、其他兩家各50，你收160。原莊家的下家、也就是你畫面對家的玩家接莊，並非胡牌的你直接當莊 |

兩種完整示例由L7-13／L7-34核對；實際檢查點包含補花待補、吃牌待回應、自摸待選擇及結算的序列化還原，沒有重摸、重取牌或重付分。這是引擎檢查，尚非課程頁的暫停／續玩功能。

### 提示、錯答與分支

提示分兩層：先「看現在輪到誰、剛才打牌的來源」，再指示示範動作。錯誤不扣分，回饋只說剛才的條件，例如「吃牌後先打牌，不需要再摸」。每段成功才給一小句具體回饋；結算只給一個下一步，不為每張牌跳阻擋對話框。

「過」仍須保留為合法回應，L7-PASS證明選過不拆手牌，接著輪到自己摸。第一版整合可在玩家偏離已驗示範主線後停在該段，說明「這是合法選擇；以下固定示範會回到剛才的教學檢查點」，由玩家按「重試這一段」才回到該段副本。不能把合法的過判成規則錯誤，也不能偷偷重排牌、強迫改吃或記為整局完成。

若要讓每一個任意合法打牌分支都繼續到結束，需另外完成開放教學對局及進度設計；本包不把兩條固定分支當作任意分支引擎。正常對戰本來就可自由選擇，課程不能遮掉合法按鈕來冒充規則。

## 第8課：換一局，自己試

目標：在不同花色及莊位下，選擇提示、完成合法操作、讀結算；知道能查說明、暫停、繼續及轉正常對戰。**不以自己胡牌或積分增加當通關條件。**

開場文字：「換一副教學示例，這次由你先判斷。可以保留提示，也能先關掉；需要時再查說明。請試著說出每次輪到誰，以及結算後誰付款、誰接莊。這是本機練習紀錄，不是牌技分數或證書。」

### 換例與接受結果

這次你是莊家，初手`134筒、789筒、456萬、789萬、56條、南南、九條`共17張；其他家手牌仍遮蔽。沒有起手花，先打九條，不能再摸一張。下家摸打紅中、對家摸打發財、上家摸打二筒。

| 任務 | 接受結果與回饋 | 牌例 |
|---|---|---|
| 上家二筒回應 | 13／34兩吃法均可；各自打掉剩下的四筒／一筒 | L8-13／34 |
| 略過吃牌 | 過是合法選項，保留原手牌，接著正常摸牌；偏離固定後續用玩家明確重試段落處理，不判為吃牌規則錯誤 | L8-PASS |
| 之後摸打 | 吃後下家摸打白板、對家北風、上家紅中，接著自己摸七條；能合法自摸 | L8-13／34 |
| 自摸結算 | 自摸1台，自己是莊家，三家各付50，自己收150；下一局自己留莊、連1 | L8-13／34 |
| 未贏的另一結果 | 在能自摸時選擇繼續打七條，下家可胡；只有自己付50，下一局下家接莊，連0。仍須能辨認放槍、台項、付款與莊位，不標「課程失敗」 | L8-R13／R34 |

未贏分支用來核對完成條件涵蓋不同結果，不要求新手故意放棄能胡的牌來通關。玩家如果選擇放棄，當下就說清過水與打牌風險；不稱它是推薦策略。此例他家胡牌是實際合法仲裁，不是教學頁直接扣分或指定贏家。

換例先不揭示等待牌與下一張；提示、回看答案及錯答推導需記本次受助。固定題序即使第二次未按提示，也只能叫「本次未求助完成」，不能宣稱首次陌生題、學習成效或公平競技。正常對戰入口始終可用，不需解鎖八課。

### 暫停、續玩與回正常對戰的整合要求

- 課程內暫停須停住本課的自動步驟；返回說明後保留當前段落，不能意外替玩家摸打。焦點回到下一個可操作位置。
- 目前前三課只存整階段旗標、不存中途局面；未實作前，離頁必須明說這一段不會續存。若整合第8課的中途續玩，另定課程局面、腳本版本、提示／分支及檢查點的保存契約，不能冒用正常Session鍵。
- 重新示範與重新發牌須清楚區分：前者同一題重試，後者固定示例再來一次，都不是洗出新的公平對戰。原稿、失敗及跨頁衝突處理沿既有保存保護，不靜默覆寫。
- 轉正常對戰先顯示「教學示例結束，正常對戰使用另一次洗牌及原存檔」。有原牌局就提供繼續原局；新開一將仍沿原覆寫確認。不能把固定牆或他家暗手帶進正式AI，也不能直接覆蓋上次牌局。
- 整合驗收須真的操作提示切換、暫停返回、重載、結算返回與正常對戰連接；本包的引擎還原測試不代替這些頁面驗收。

## 實桌附錄：網頁替你做了哪些事？

這一節是給已學完網頁流程、準備看懂實體牌桌的新手。只說概念與要問的問題，不替未約定的牌桌裁罰。

| 實桌常見步驟／名詞 | 給玩家的說明 | 網頁差異及開打前要問的事 |
|---|---|---|
| 抓位 | 決定四人的座位，可用混合的東南西北牌配合擲骰／抽牌 | 本頁已安排畫面座位；實桌先確認如何抓位、何時換位，不把抓位和之後每次換莊混為一談 |
| 起莊 | 決定第一位莊家；之後依桌規續莊或換莊 | 網頁正常局由引擎決定初莊，教學例明示固定莊家；實桌確認採何種起莊方式，不背成抽東必永遠當莊 |
| 洗牌、砌牌 | 洗混後把牌疊成牌牆；若用本案144張，四邊、每墩兩張的數量圖解是每邊18墩 | 網頁直接洗牌成一列；實桌核對完整牌數及花牌是否採用，不把網頁的陣列外觀當實桌取牌教學 |
| 擲骰、開門與取牌 | 決定起牌位置，再按桌上約定從牌牆依序取牌 | 骰子數、從哪邊開始數與開門法需當桌示範確認。本專案沒有骰子／砌牆模擬，不能聲稱已練過手勢與精確取牌程序 |
| 補花與槓後補牌 | 花另放、從補牌端補；槓的實體牌多一張，但仍只算一組 | 網頁自動判定補牌位置與待補狀態。數牌不能看到18張就一律說相公，要先看已槓幾組、花是否另列、目前是否欠補 |
| 相公 | 牌數或取打牌等行為出錯的俗稱，細分及後果依桌規 | 網頁拒絕非法操作，沒有新增「相公自動通賠」制度。實桌有疑義先停下核對，不先把手牌推倒 |
| 詐胡 | 尚不符合當桌合法胡牌條件卻宣告／示意胡牌；不因名稱就推定一定故意作弊 | 網頁只提供引擎判定合法的胡牌，沒有另設懲罰；實桌如何處理需先約定 |
| 海底與牌尾 | 桌上各家打出的牌是海底；未摸完的牌尾及保留牌是另一件事 | 本案固定保留16張、槓不加留；別桌的留牌、過水、明槓與花胡可能不同，先確認 |

抓位／用語概念參考[明星3缺1抓位指南](https://www.gametower.com.tw/Games/Freeplay/MJ/Star31/knowhow/%E4%BC%91%E9%96%92%E9%BA%BB%E5%B0%87%E6%8A%93%E4%BD%8D%E6%8C%87%E5%8D%97.aspx)及[官方術語頁](https://www.gametower.com.tw/Games/Freeplay/MJ/Star31/Data/jargon.aspx)；相公／詐胡概念參考[華人麻將系統台灣規則](https://leyi.com.tw/rule/tw)的對應條目（2026-10-17搜尋索引可讀，正文擷取502）。只轉述概念，沒有搬用其他平台的罰分、暗槓解過水、連莊上限或槓後加留牌等規則；外部網站與本案不同時，一律依凍結RULES。來源的精確起牌程序不一致，本附錄不指定全台唯一骰法。

### 上實桌前，先問這六件事

1. 這桌打十六張嗎？有沒有八張花？怎麼抓位、起莊、開門與補牌？
2. 一底幾分、每台幾分？有無起胡台數、封頂、未列牌型或特殊花台？本網站的30／10不能自動帶到別桌。
3. 吃後禁打哪些牌？可不可以明槓上家？尾局何時禁止吃碰槓？
4. 怎樣算過水、過碰、回吃碰，什麼時候解除？
5. 花胡、搶槓、多人要胡、流局續莊及連莊怎麼算？
6. 牌數拿錯、摸錯、宣告錯誤時如何停下確認與處理？先知道約定，不現場套用網路上看到的罰則。

## 整合交接與驗證範圍

測試的0／1／2／3是席次內碼，畫面文字只顯示你／下家／對家／上家。
