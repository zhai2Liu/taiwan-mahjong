# 台灣麻將新手學習路線與用語調整提案

2026-10-13 更新：S0.1 已採納兩條學習路線，方向見 [PRODUCT-DIRECTION](PRODUCT-DIRECTION.md)，八課列入 S2 後續工作；尚未實作。以下保留當時提案與盤點，舊「待採納／維護不擴充」不代表現行決議。

## 1. 建議決策

將產品定位擴充為「台灣十六張麻將學習與決策訓練」，提供兩條可自由切換的入口：

- **從零學台灣麻將**：認牌、讀桌面、完成一局、理解基本胡牌與計台。
- **練習判斷與牌效**：保留現有純練習、出牌後解釋、局後檢討及情境題主線。

這是學習路線的擴充，共用同一套 TW16-CLASSIC-v1 引擎。進階玩家可直接進原入口，不必先通過新手課程。遊戲對戰仍可直接開局。

現行 PRODUCT-DIRECTION.md 把新手教學列為「維護不擴充」；若採納本提案，應明確更新該項及 ROADMAP，不能一邊保留舊限制、一邊宣稱完整新手路線已成為主線。本次只提出調整方案，尚未改寫已採行決議。

## 2. 現況與缺口

現有 src/tutorial-view.ts 是六步操作導覽，含認牌、示範捨牌、134遇2的兩種吃法、碰槓與過、胡牌形及提示說明。優點是與正式存檔隔離、原生視窗、可用鍵盤；可保留為「操作快速導覽」。

不足之處：

1. 第一步同時塞入牌種、牌數、牌組、補花及特殊花胡，新手還沒建立基本圖像就接觸例外。
2. 缺完整的一輪摸打與他家回應演練，沒有循序教上家／下家、中央棄牌區、桌上牌組。
3. 大部分步驟可以直接按下一步，閱讀完成不能證明會辨識牌組、聽哪些牌或做合法操作。
4. 計台、座位風牌、莊家、連莊與換圈缺可操作例子，無法靠導覽獨立理解結算。
5. 缺可中途離開再回來的課程進度，也缺從教學移轉到一局正常對戰的驗收。

不應把目前「純練習模式」當作完整麻將入門課：它刻意沒有對手、花牌、吃碰槓、計台，適合後續牌效練習。

## 3. 用語盤點與原則

本次搜尋玩家可見的教學、牌桌、練習、檢討與試讀文字，未發現把立直、振聽、寶牌、役滿、榮和當成本桌玩法的例子。「不是日麻振聽」只出現在題庫內部 scope；程式內 ron 在畫面已顯示「胡牌」。這是限定檔案盤點，不代表已逐頁驗收所有情境。

「面子」不宜直接判成日麻專有詞。台灣遊戲官方《明星3缺1》的[術語頁](https://www.gametower.com.tw/Games/Freeplay/MJ/Star31/Data/jargon.aspx)也使用面子、過水、海底、門風及圈風。此來源只協助判斷台灣玩家用語，不代表所有桌規一致；其流局留牌、連莊上限等內容不能直接覆蓋本案 RULES。

重點是「白話先行、術語可查、同一概念一致」，不是全面搜尋取代。

| 現有詞 | 建議第一層文字 | 必須保留的界線 |
|---|---|---|
| 五面子一對將 | 五組完成的牌，加一對相同的牌 | 再教順子／刻子／槓及將牌；槓有四張實體牌，不能永遠套成總實體17張 |
| 面子／搭子 | 完成的牌組／還差一張的組合，配牌圖 | 「幾搭」在牌桌語境有不同算法，不能直接等同向聽或胡牌距離 |
| 副露 | 亮出的吃、碰、明槓牌組 | 暗槓另列，不誤顯示對手暗槓牌種；技術資料的 meld 不一律翻成副露 |
| 向聽 | 牌型距離；聽牌／至少還需 N 次有效改善 | 進階說明保留向聽數；不是再摸 N 次就會聽，也不是剩 N 組牌 |
| 有效進張 | 能讓牌型更接近聽牌／胡牌的進牌 | 在聽牌階段改說可完成胡牌牌型的牌；實際胡牌資格另判 |
| 公開有效進張／未知一般牌 | 依目前看得到的牌，估算還有幾張可改善的牌 | 對戰分母含別家暗牌與牌尾，不標成牌牆摸中率；純練習的牌池比例另說明 |
| 牌河 | 中央棄牌區（各家打出的牌，俗稱海底） | 保留牌尾稱「牌尾保留牌」，最後可摸牌另稱；不要把海底的不同意思混在一起 |
| 門清 | 沒有吃、碰、明槓的狀態，再依本桌說明 | 暗槓與門清關係依凍結桌規，不簡化為「所有牌都沒放上桌」 |
| 流局／一將 | 本局無人胡牌／打完東南西北四圈 | 連莊會增加局數；一將不是固定16局 |
| 圈風／門風 | 這一圈的風牌／你目前座位的風牌 | 搭配莊家與四座位置示意，不只換成另一個陌生詞 |

胡牌、自摸、放槍、聽牌、吃碰槓、過水、連莊、台數等桌上需要使用的詞保留，在第一次出現時用牌例解釋。筒／餅、索／條等別名可收於小詞典，不必讓每個按鈕同時堆滿別名。

若後續實際發現「役、立直、振聽、寶牌、符數」等被當成本桌規則，列為規則／文案缺陷，優先修正。過水不得直接改名為振聽。內部 shanten、ron 等 API 不因文案在地化大量改名，避免不必要的程式與存檔遷移。

## 4. 完整新手課程藍圖

每課採「一個目標 → 短圖解 → 親手做 → 解釋原因 → 換例再試」，可略過與重練。閱讀、練過、獨立完成分開標示。

| 課程 | 要學會的事 | 驗收互動 |
|---|---|---|
| 1 認牌與認桌面 | 萬筒索、字牌、花牌；自家牌、他家暗牌、棄牌區；上／下／對家 | 找出指定牌與來源；辨認字牌不能組連號 |
| 2 輪到我做什麼 | 未吃碰槓的16→17→16示例、莊家先打、摸打輪流、補花 | 完成一輪摸打；指出下一個行動者與補花的位置 |
| 3 怎樣才是胡牌形 | 五組加一對；順子、刻子、將牌，牌不可重複使用 | 選取並檢查牌組，至少一組不合法反例；另教槓的實體張數 |
| 4 吃碰槓與放棄 | 吃只取上家、碰與槓、補牌、回應優先、本桌禁捨 | 134遇2兩吃法、不能吃對家、吃碰後選合法捨牌；槓另用短題 |
| 5 聽牌與胡牌 | 找等待牌、胡別人捨牌與自摸、放槍、按過及過水 | 找出可胡牌種；區分牌型已完成與目前被過水限制；不先背向聽公式 |
| 6 看懂本桌計台與續局 | 底／台、自摸與放槍付款、門清／三元／正花例子、莊與連莊 | 讀一份已結算明細；分辨誰付、莊是否續留，不重算或發錢 |
| 7 陪你走一局 | 將前六課串起來，理解每次停下來是在等誰 | 教學示例牌局逐步操作到結算；關鍵時刻暫停，提示可逐步減少 |
| 8 自己試一局 | 選擇提示程度、遇到問題會找說明、能續玩 | 使用另一個未練過的例子與正常對戰；完成不以是否胡牌判定 |

完成標準是能認牌、組牌、合法摸打回應、理解胡牌／自摸／放槍與讀懂基本結算，不是保證勝率或高台。過水、尾局、特殊花胡等例外必須可查，必要時在課內示範，但不在第一屏全部塞給新手。

補一份可選的「第一次坐上實體牌桌」圖解：抓位／起莊、洗牌砌牌與擲骰取牌的用途、補花與口頭喊牌、手牌張數錯誤（相公）、未達條件喊胡（詐胡），以及開打前確認桌規。說明哪些操作由網頁代勞，避免只學會按按鈕。實體流程與罰則另有桌規差異，不因此增加本版遊戲的罰分或改凍結規則。

後續銜接：自行行牌 → 理解等待牌 → 純牌效練習 → 出牌後比較 → 局後檢討 → 進階情境題。基礎課和進階題的完成紀錄、提示使用、成效指標分開；若保留測驗題被拿進教學，必須移除其保留資格。

## 5. 最小實作方式與維護要求

- 六步舊導覽保留作快速操作說明，完整課程用獨立學習入口，避免把同一彈窗擴成巨大說明書。
- 重用牌面、引擎合法動作、計台結果及教練證據；不寫另一套簡化規則引擎。固定示例牌局標明是教學範例，不能包裝為公平隨機對戰。
- 初期課題以原生按鈕選牌／配對為主，不強制拖拉；鍵盤、觸控、焦點及螢幕閱讀文字一起驗證。
- 課程內容先用少量明確資料與情境函式，不建立通用課程平台、後端、帳號、AI聊天老師或自動自由文字評分。
- 新手進度如需保存，使用獨立版本鍵，提供重練／清除，壞檔保留及保存失敗提醒；不得動既有對戰、練習與局後記錄。
- 用語先維護一份小型對照表，必要時共用既有格式函式；不為幾十個詞導入多語系框架。逐項檢查對戰、練習、教學、題庫、結算、無障礙標籤與匯出。
- 修題文字前補題目版本追溯，保留舊作答的原意；新手課也要記課程版本。不能因文字改版悄悄重評歷史答案。
- 每個工作包更新 HANDOFF；正式方向採納後再更新 PRODUCT-DIRECTION、ROADMAP、README。驗收記錄保留哪些是自動測試、模型複核、真人理解與實機結果，不混稱已通過。

## 6. 建議順序與資源安排

| 工作包 | 內容 | 相對投入 | 通關條件 |
|---|---|---|---|
| B0 用語與資料基礎 | 確認方向；完成詞表、題目版本與離頁保護；修正最難懂的主要標籤 | 小至中 | 相同概念顯示一致，舊作答仍可辨版本，沒有改變規則或算法 |
| B1 入門前三課 | 認牌、摸打、胡牌組成，可中斷續學 | 中 | 新手能以另一個牌例完成任務，不靠連按下一步通關 |
| B2 動作與結算 | 吃碰槓、聽胡過水、計台續局 | 中 | 正／反例經凍結引擎核對，三種輸入方式可操作 |
| B3 串接與真人試讀 | 引導一局、獨立一局、銜接進階入口；逐步減少提示 | 中至大 | 首批可找3–5位實際新手作形成性試讀，記錄卡點與修訂；不把小樣本當普遍學習成效 |

B0先做；B1完成就可先收新手理解回饋，不必等所有課上完才驗證。既有進階路線維持可用，持續處理收到的試讀資料；正式前後測仍有自己的難度／題族／首次曝光門檻。

Sol主導規則邊界、核心實作與整合。Luna可負責限定的用語盤點、課文試讀、文件對照；不能代替真人新手或獨立規則證據。常規不需 Astra。

本評估未跑測試或部署，沒有新增課程功能。外部術語來源於2026-10-13查閱；程式現況以本次 src 與 HANDOFF 為依據。
