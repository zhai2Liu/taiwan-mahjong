# 玩家用語：台灣牌桌俗稱優先

2026-10-13｜使用者已要求先調整用語；完整新手課程仍為另案提案。

## 目前採用

| 概念／原用詞 | 主要顯示文字 | 維護界線 |
|---|---|---|
| 索 | 條；首次教學補充「也叫索」 | 牌種代碼 s 不改；筒仍作主詞，教學補充「也叫餅」 |
| 將／將牌 | 眼睛、一對眼睛 | 解釋為兩張相同牌，不能把兩張牌必定指定為最終眼睛 |
| 面子 | 完整牌組；胡牌目標「五組牌加一對眼睛」 | 吃碰槓與暗手牌組都可算；槓四張實體牌仍只算一組 |
| 刻子 | 三張同牌 | 沒有實際碰來的牌不能標成已碰；三暗刻等計台名稱保留 |
| 副露 | 已亮出的牌組／吃碰明槓 | 顯示全部 meld 的區域稱桌上牌組，因為也含暗槓 |
| 牌河 | 海底／中央海底 | 指各家打出的牌；牌尾保留牌及最後可摸牌分開說明 |
| 單騎／兩面 | 單吊／雙頭 | 只改呈現，不改獨聽、平胡等計台判定 |
| 捨牌／暗手 | 打牌／手牌 | 對手暗槓仍遮罩；內部 ID、Intent 與資料欄位不改名 |
| 向聽數 | 聽牌、至少再 N 次有效進牌可聽牌 | 由 listeningDistance 統一顯示，不等於摸牌次數、搭數或剩餘牌組數 |
| 公開有效進張 | 依可見牌計的有效進牌 | 保留張數與分母；對戰不是實際摸中率，純練習牌池機率另說明 |

胡牌、自摸、放槍、吃碰槓、過水、門清、連莊、圈風、門風、台數、一將等桌上用語保留。來源規則／計台文件及歷史驗收不全面改寫，避免失去追溯；進階分析內部可使用 shanten、面子等技術詞，但玩家主畫面以本表為準。

「面子」也見台灣遊戲官方[明星3缺1術語頁](https://www.gametower.com.tw/Games/Freeplay/MJ/Star31/Data/jargon.aspx)，本次改為牌組是使用者偏好與可讀性調整。外部遊戲的用詞不代表桌規完全相同；TW16-CLASSIC-v1 仍為唯一規則基準。

## 題庫與作答追溯

改動兩份原始題庫的題幹、選項、推導及牌面標籤；題號、答案 ID 集合、牌種、預期計算及保留候選身分不變。沒有將保留題加入試讀。

新版匯出 schemaVersion=2，增加 contentRevision：建置時對九題的題幹、全部選項、答案、推導及牌面計 SHA-256。此標記不是身分／防偽證明；只用來辨別內容版本，不包含使用者理由或回饋。

本機審閱工具仍支援 schema 1。schema 2 若版本不同，已提交紀錄轉人工核對；即使標記相同，題幹及已選文字不符也轉人工。schema 1 仍只比較目前可對照文字，提示缺完整版本。沒有理由自動評分、總牌技分、自動上傳或舊檔改寫。
