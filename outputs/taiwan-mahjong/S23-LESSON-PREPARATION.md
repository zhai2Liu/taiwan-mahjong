# 第4–6課：教材與引擎牌例準備

2026-10-17，S2.3準備包。依[產品方向](PRODUCT-DIRECTION.md)及[企畫第5節](MASTER-IMPROVEMENT-PLAN.md)，交付下列課文、示範／換例任務、逐步回饋及可重跑的[引擎牌例](test/learning-next.test.mjs)。**這是供整合的教材；目前網站仍只有前三課，S2.3互動頁及真人理解驗收尚未完成。** 正式整合沿前三課試用／修訂順序，不能拿程式通過代替新手能理解。

唯一規則基準為[TW16-CLASSIC-v1](../taiwan-mahjong-m0/RULES.md)。這是本專案選定的台灣十六張桌規，並非全台通用桌規。玩家文字沿用[在地用語](LOCAL-TERMS.md)；「完整牌組、一對眼睛、條、海底、單吊、雙頭」優先，不引入其他麻將的宣告或台數門檻。

## 第4課：別人打牌後，我能做什麼？

目標：看清誰打牌，選出合法的吃／碰／過，取得牌後完成下一步；槓另用短例學習，不把全部例外塞進第一次吃牌操作。

### 給玩家的短圖解

吃，是拿上家剛打的一張牌，和你手中兩張湊成同花色的連號三張；碰，是拿任何一家剛打的一張牌，和你手中的兩張相同牌湊成三張。沒有要拿就按「過」，繼續等這次回應結束。有胡牌機會時選過，會有第5課介紹的過水限制。

先選回應，再等這張牌由誰取得：胡優先於碰／明槓，碰／明槓又優先於吃。不是誰按得快就拿到。多人同時要胡，本桌只由沿行牌順序距出牌者最近的一家胡，叫攔胡。吃或碰成功後，**先打出一張合法的牌，不再摸一張，也不能立即開槓或自摸。** 被別人優先取得時，原本選吃／碰的手牌不會拆開。

本桌吃牌後不能立即打出「能和剛才自己用的兩張牌湊成順子」的牌；碰後不能立即打出同種牌。畫面應明說禁打原因，不能只把牌變灰。

### 示範與換例

示範手牌：`134萬、147筒、147條、東南西北中發白`，共16張。上家剛打二萬，牌尾可用張數大於3。先只顯示問題與牌面，玩家提交後才顯示本表答案／回饋。

| 步驟 | 玩家任務與接受答案 | 提示或操作後回饋 | 牌例 |
|---|---|---|---|
| 找來源 | 指出剛打牌的是上家；對家打二萬時不能吃 | 「吃只拿上家的牌；對家這張可以考慮合法碰或胡，不能吃。」 | L4-G13／G34 |
| 找全部吃法 | 選一萬＋三萬成123，及三萬＋四萬成234；兩種都合法 | 第一次提示只說「把二萬放在連號中間或前端試試」，再求助才亮兩組 | L4-G13／G34 |
| 實際吃一次 | 任選一種均接受，不評為唯一最佳打法；等仲裁後再取牌 | 「你用一、三萬吃成一二三萬，四萬還留在手中。」或「你用三、四萬吃成二三四萬，一萬還留在手中。」 | L4-G13／G34 |
| 完成下一步 | 選目前合法牌打出；打後手牌加桌上牌組回到待進牌狀態 | 13吃2禁打2；34吃2禁打2、5。「已吃好並打完，接著等下一家的動作。」 | L4-G13／G34 |
| 換例自行做 | 改成134筒，其餘兩門各147及七種字牌，上家打二筒；再找兩吃法並完成一次打牌 | 先不亮答案；同樣接受13或34，不以選哪一吃法判牌效優劣 | L4-T13／T34 |
| 碰的短例 | 手牌有三張五萬，任一家打第四張時選碰，再打白板等合法牌 | 「碰可取任一家；手上留下的第四張五萬，這次不能立即打出或加槓。」 | L4-P |
| 看仲裁 | 同一張二萬同時有人要吃、有人要碰、有人要胡；再分別讓胡者／碰者選過 | 依次由胡者、碰者、吃者取得；沒有取得牌的人維持原手牌 | L4-AWIN／APON／ACHI |

摸打時一般是手上16→17→16；吃碰時並不是手中再加到17張。吃後手中14張、桌上一組按3張計，打後13張加桌上一組，仍是同一個五組加眼睛的結構目標。

### 槓的獨立短例

| 短圖解／任務 | 觀察重點與回饋 | 牌例 |
|---|---|---|
| 暗槓：自己有四張五萬，在自己的合法選擇階段開槓，再補東風 | 槓後先補牌；四張只算一組。此例補好共有18張實體牌，仍可五組加眼睛。其他人看不到暗槓牌種 | L4-KC |
| 明槓：手上三張五萬，對家打第四張，選明槓、補東風 | **本桌不能明槓上家。** 明槓補成胡牌形狀，這次打牌前仍不能一般自摸，不要教成「槓後補到就一定能胡」 | L4-KO |
| 加槓：已碰五萬，再持有第四張，自己的合法選擇階段提出加槓 | 先等搶槓；無人胡才正式成槓、解除本桌過水，再補牌。不能在吃碰後直接加槓 | L4-KA |
| 加槓被搶 | 原碰仍是三張，第四張由胡牌者取得；加槓者不補牌 | L4-KR |

暗／加槓通常在自己的摸補後選擇；莊家起手也可合法暗槓，不能因教材句子省略而另禁。明槓後的禁一般自摸在本次打牌前持續，連續補花或再開暗／加槓也不能繞過；花胡是獨立例外。三種槓分別呈現，不以一個「槓＝補牌後可自摸」結論概括。

補充說明放在完成主線之後：牌尾可用張數只剩3張以內，不能吃、碰、明槓；4張仍可吃（L4-E）。有牌可補時暗／加槓另判。自己最後打的同種牌暫不能回吃／碰；放棄合法碰會記過碰，到自己下次打牌後才清除，摸牌或補花不清。現有引擎E14、E17、E32、E35、E36分別核對這些界線，不另寫一份教學規則算法。

## 第5課：聽什麼，不一定現在就能胡

目標：找出全部等待牌，分辨自摸、胡別人與放槍；能說出「牌型完成」和「現在合法能胡」的差別。

### 給玩家的短圖解

再進一張就能湊成五組牌加一對眼睛，叫聽牌；可能同時聽好幾種牌。自己摸到並合法完成，叫自摸；別人打出而由你合法胡牌，出牌者叫放槍。本桌不需要按一個按鈕宣告聽牌，也沒有至少一台才能胡的門檻。

找聽口先看牌型；海底已出多少張影響還有沒有機會進牌，不會直接把結構上的聽口改成別的牌。本課不把可見牌比例寫成下一次一定摸中的機率。

本桌自願放棄**當下合法能胡**的機會，會過水，全部聽口的一般胡、自摸、搶槓都受限制。不是只不能胡剛放過的那一種，也不是再摸一張或改聽就自動解除。

### 示範與換例

| 任務 | 接受答案與操作後回饋 | 牌例 |
|---|---|---|
| 示範找聽口 | `34萬、456筒、234筒、345條、789條、東東`：選二萬、五萬。兩種都要找出；只選一種時提示重新檢查34的兩端 | L5-G |
| 分辨來源 | 上家打二萬是胡別人；自己摸五萬是自摸。此時尚無過水，兩者都各有合法胡牌機會 | L5-G |
| 換例找聽口 | `123萬、567萬、345筒、678條、22筒、發發`：二筒或發財。另一對留眼睛；紅中不能補成這副牌 | L5-T |
| 選過的代價 | 在第一副牌真的放過二萬，輪到自己摸五萬：牌型完成，仍不能一般自摸；打回五萬仍過水 | L5-P |
| 實際解除 | 同一副牌放過後改摸九萬，打九萬後仍聽二／五萬；九萬不在新聽口，這次出牌提交後解除。下一家打二萬便可胡 | L5-R |
| 改聽反例 | 過水中摸五萬，改打四筒：新聽口是一／四／七筒，四筒仍在其中，所以沒有解除 | L5-C |
| 另一種不能胡 | 回看明槓補成牌的例子：不能一般自摸來自明槓限制，並非另外放過一次胡 | L4-KO |

過水提示先說「你剛才有合法胡牌機會但選了過，現在尚未解除」，第二層才教檢查打牌後的聽口：**打出去的那種牌不在新聽口，出牌提交後才解除。** 不用「隨便打一張就解」「換聽就解」等口訣代替條件。

L5-C不只存在一種拆法：留下的筒牌是23456，進一筒可拆123＋456；進四筒可拆234＋456；進七筒可拆234＋567。其餘345萬、345條、789條與東東不變。不能把它只教成四／七筒雙頭。

錯答回饋：「你找到了能補成牌型的牌；現在再看過水是否已解除。」答對回饋：「你分開確認了聽口和當下胡牌資格。」不把熟例答對標為已證明實戰學會。

進一步說明：曾打過某牌，不會因此一律不能胡該牌（L5-H）；不是套用其他麻將的整套限制。被其他人攔胡不算自願放過；放棄合法自摸也會過水；摸花／暗槓不自行解除；加槓須未被搶且正式成立才解除（L4-KA／KR）。花胡另有例外，暫不混入首次普通聽胡任務。完整界線沿現有引擎E04、E12、E31、E34核對。

## 第6課：看懂這一局為什麼收這些分

目標：讀逐條台項、付款對象與分數變動，知道下一局誰當莊。先會讀結算，再提供拆法細節，不要求新手背完整台表。

### 給玩家的短圖解

本桌一底30分、每台10分。普通胡別人由放槍的一家付；一般自摸由其餘三家各付。結算先逐條列出實際成立的牌型，再看每一家付款：這筆涉及莊家才加莊家1台及連莊2N台。畫面的牌型台數不一定等於每家付款時用的台數。

門清加自摸以「門清一摸三」3台呈現，不能再把門清、自摸各加一次。紅中、發財、白板須形成三張同牌或槓才有三元台，不是手上有一張就有台；較大牌型的取代關係仍以實際結算為準。

花也不是拿幾張就幾台。正花按本局門風對應：東春梅、南夏蘭、西秋菊、北冬竹；一組四季或四君子成花槓時，取代同組正花，另一組的正花仍另算。課內先教讀明細，不要求背完整花胡矩陣。

### 示範：東門莊家連2，自摸

手牌 `123萬、456萬、789筒、中中中、發發發、77條`，最後自己摸進七條；花有春、梅、夏。並非第一巡特殊胡，也非槓補或最後可用牌。此例對應L6-G：

| 胡牌明細 | 台數 | 為什麼 |
|---|---|---|
| 門清一摸三 | 3 | 未吃碰明槓加槓且一般自摸；門清、自摸不重複列台 |
| 紅中 | 1 | 三張紅中 |
| 發財 | 1 | 三張發財 |
| 2花（正花） | 2 | 東門春、梅各1；拿到的夏不是本門正花 |
| 獨聽 | 1 | 此牌型胡前僅聽七條、補成眼睛；不是看到一對就一律加台 |
| 牌型合計 | **8** | 還不含每筆付款的莊連台 |

任務分三步：先找哪兩張花有台 → 選出付款者 → 讀下一局莊位。提交後給回饋：「你分清了3張花和2張正花，也找出三位付款者。」

本局結算用**本局開始時的連2**：莊家1＋連莊4，所以每一家付 `30＋10×(8＋1＋4)＝160`。四家變動是莊家＋480，其餘各−160；下一局才變連3。重開結算或重載不會再付款一次。

### 換例及反例

| 任務 | 已知情境、接受答案與回饋 | 牌例 |
|---|---|---|
| 換例讀明細 | 莊家仍東門連2；南門已吃123萬，手中456萬、234筒、345條、中中、南南，西門打紅中。南門花有夏、春。胡紅中後只有紅中1＋正花夏1＝2台；未門清，不加門清一摸三，原本兩對各等第三張也不加獨聽 | L6-T |
| 換例看誰付 | 上例只有西門放槍付50；東門莊家未涉及這筆，不加莊連。四家變動東0、南＋50、西−50、北0；下一局原莊家下家南門當莊、連0 | L6-T |
| 自摸不一定同額 | 改為南門自摸同樣8台、南門正花夏蘭；東門仍連2。東付160，其餘兩家各付110，南收380 | L6-P |
| 換莊不等於胡者坐莊 | 西門胡北門放槍，原東門是莊家：下一局南門當莊，並非西門 | L6-N |
| 零台也可胡 | 已吃123萬、手中45萬＋234筒＋345條＋789條＋東東，非莊打六萬；無花且不是門清，0台仍可胡。此例胡者、付款者都非莊，支付一底30分 | L6-Z |
| 花槓取代 | 示範牌改持春夏秋冬梅：四季花槓2台、梅正花1台，花共3台；其他牌型同前，合計9台。不可算成5花5台，也不可再重加春正花 | L6-F |
| 流局 | 沒人胡、可用牌耗盡，四家0變動；莊家仍留莊並由連2變連3。不放槍不代表成功阻莊 | L6-D |

結算互動只讀引擎已完成的`settlement.score`／`delta`，逐條名稱重用`scoreLines`；不得為教學重新計台或重新付款。純花胡付款、全求人、大三元取代等例外先提供規則查閱，不把它們硬塞進本課一次測完。

## 整合與驗收交接

本包交付的是教材及26個具名自動牌例。測試中的m／p／s／z為內部牌種代碼，玩家呈現換成萬／筒／條與字牌名稱；不顯示GameState、E16或機器代碼當提示。未指定的他家手牌由既有fixture補齊且每一步`assertState`核對，沒有略過牌權檢查。這些固定牌序只能標「教學示例」，不能寫入正常Session或交給正式AI當公平對戰。

實作時沿現有[learning-model](src/learning-model.ts)、[learning頁](src/learning.ts)、牌面與原生按鈕，不建通用課程平台或第二套仲裁／過水／計台引擎。桌面／窄畫面、鍵盤焦點、提示分層、錯答後再試沿前三課；選過、吃法或槓回應都送正常引擎，等仲裁成功才顯示取得牌與下一步。只在完成操作後給具體回饋，別每張牌跳確認窗。

同一課可分段、返回與重練；使用提示、回看答案或錯答推導後完成要和未求助完成分列，場外協助由真人試用記錄，不能自動認定陌生題。換例只是不同牌例，不自稱通過正式能力測驗。完成條件是合法操作及能讀懂結果，不是必須胡牌或收分。

### 三課進度擴充先決事項

現有`tw16:learn:v1`只接受`beginner-1-3-v1`三筆，這輪完全不改它。正式擴課時先定新課程版本及轉換：保留原前三課read／guided／independent原值，第4–6課三種旗標全為false；新增課文不可讓舊完成旗標自動代表新內容已學會。壞檔、未知版或保留原文失敗時停止覆寫，仍允許本頁練習；不得清空網站資料當遷移。

轉換前保留可下載的舊原文並取得使用者明確操作；核對當下原檔與Web Locks，並留可回復原紀錄的路徑。正式整合包必須先測有效舊檔、壞檔、未知版、容量／寫入失敗、跨頁衝突、重載及對戰／練習／檢討／試讀五類資料不受影響。格式與回退細節要在實作前定稿，本文件不是已完成的遷移功能。

### 可重跑與後續工作

在遊戲目錄先`npm run check`，再`node --test test/learning-next.test.mjs`；全套用既有`npm test`，不新增套件。L4有13項、L5有6項、L6有7項。普通過水放棄自摸、攔胡、尾局及花胡等未重複鋪測的邊界沿[test/engine.test.mjs](test/engine.test.mjs)；計台取代沿[test/scoring.test.mjs](test/scoring.test.mjs)。牌例結果只能證明本專案引擎與教材吻合，不是台灣所有桌規或真人理解的證明。
